# UI Requirements HIGH LEVEL

## UI DRYER
The system shall provide the user with the ability to start, pause, and resume a dryer cycle, select cycle parameters including cycle type, temperature, and time, monitor the active cycle through visual indicators, and enable optional features such as Wrinkle Care.

### SELECTOR KNOB (CYCLES AND TEMPERATURE)

The system shall allow the user to configure the dryer operation by selecting the desired drying cycle, temperature setting, and cycle time, including available automatic temperature option.

**Cycle:**
- Cottons
- Casuals
- Mixed Load
- Delicates
- Quick Fluff

**Temperature:**
- Regular
- Medium
- Low
- Auto

**Timeed Dry:** 
- 90 min
- 60 min
- 45 min
- 30 min

### BUTTONS 

The system shall allow the user to start, pause, and resume a drying cycle and enable optional cycle feature as Wrinkle Care.

### INDICATORS
The system shall provide visual feedback to indicate active cycle states, operating modes, and status conditions.

- Damp
- Drying
-Cooling
- Wrinkle Care

### BUZZER

The system shall provide audible feedback in response to user actions and appliance events, including selector knob adjustments, cycle initiation, and cycle completion.
