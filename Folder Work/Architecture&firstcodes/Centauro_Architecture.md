# Electronic Architecture

## 1. Power Pins

| Pin | Signal | MCU Function Acronymus | Description |
|------|---------|-------------|-------------|
| 4 | VSS | VSS | Ground reference |
| 7 | VCC | VDD | Main power supply |
 
### Description

The power pins provide the electrical supply required for the MCU operation. 

### Functionality

- Provide operating power to the MCU.
- Establish the reference voltage for all digital and analog signals.
- Support proper execution of firmware and peripheral functions.
- Supply the internal logic, communication interfaces, and I/O peripherals.

---

## 2. Programming and Debug Interface

| Pin | Signal | MCU Function Acronymus |
|------|---------|-------------|
| 13 | RESET | RES |
| 16 | SWCLK | P300 / SWCLK |
| 17 | SWDIO | P108 / SWDIO | 

### Description

The SWD interface is used for firmware programming and debugging.
RESET remain available for device recovery and low-level
programming operations. 

### Functionality

- Supports real-time debugging during firmware development and validation.
- Allows access to internal MCU resources such as registers, memory locations, and execution states.
- Enables firmware download, update, and verification operations.

---

## 3. GPIO Outputs

### Heartbeat Indicator

| Pin | Signal | MCU Function Acronymus |
|---------|-----|---------|
| 24 | GPIO_HEARTBEAT | P100 |

### Description
Indicates normal firmware execution and system activity. 

### Functionality
- Indicates that the MCU firmware is executing correctly.
- Provides a visual indication of system activity.
- Changes state periodically while the application is running.

### LED Outputs

| Pin | Signal | MCU Function Acronymus |
|---------|-----|---------|
| 25 | GPIO_LED01 | P015 |
| 26 | GPIO_LED02 | P014 |
| 27 | GPIO_LED03 | P013 |
| 28 | GPIO_LED04 | P012 / AN004 |
| 29 | GPIO_LED05 | P009 / AN003 | 

### Description

Provides visual feedback to the user about their behavior in the current function.

### Functionality
- Indicate the current operating status of what process is working.
- Show active user selections and configured options.


---

## 4. GPIO Inputs

### User Buttons

| Pin | Signal | MCU Function Acronymus |
|---------|-----|---------|
| 22 | GPIO_BUTTON01 | P102 |
| 23 | GPIO_BUTTON02 | P101 | 

### Description

These inputs are connected to user interface buttons and are used for
system interaction and control. 

### Functionality
- Detect user button activations and state changes (as Start or Pause cycle).
- Trigger system actions based on user commands (as Deep Rinse or E Dry).

---

## 5. HaierLink Communication Interface

| Pin | Signal | MCU Function Acronymus |
|---------|-----|---------|
| 18 | TX_HAIERLINK | P109 |
| 19 | RX_HAIERLINK | P110 |
| 20 | GPIO_HAIERLINK_BUS_BUSY | P112 | 

### Description

The interface allows data exchange between the UI board and external system modules. The BUS_BUSY signal indicates communication bus availability and helps prevent communication conflicts.

### Functionality
- Transmit data to external system modules.
- Receive data from external system modules.
- Exchange control, status, and diagnostic information.
- Monitor communication bus availability through the BUS_BUSY signal.

---

## 6. PWM Outputs

### Buzzer Control

| Pin | Signal | MCU Function Acronymus |
|---------|-----|---------|
| 12 | PWM_BUZZER_FREQUENCY | P207 | 

### Description
Is used to control the buzzer and generate audible indications for the user interface.

### Functionality
- Generate audible alerts through the buzzer when a cycle is ending.
- Control the frequency of the generated tone.

---

## 7. ADC Inputs

### Hardware Identification Channels

| Pin | Signal | MCU Function Acronymus |
|---------|-----|---------|
| 30 | ADC_SEL_KNOW01 | P008 / AN002 |
| 31 | ADC_SEL_KNOW02 | P011 / AN001 |
| 32 | ADC_SEL_KNOW03 | P010 / AN000 | 

### Description

These ADC inputs are connected to resistive divider networks used to
identify hardware variants, product personality, or board
configuration during system startup. 

### Functionality
- Measure analog voltage levels generated by the selector knobs.
- Detect the active position of the connected rotary selectors.
