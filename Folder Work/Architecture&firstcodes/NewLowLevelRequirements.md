# Electronic Architecture

## 1. GPIO Outputs

### Heartbeat Indicator

### Description

GPIO output used as a heartbeat indicator to provide a visual representation of firmware execution and UI board activity.

### Functionality
Indicates that the MCU firmware is executing correctly, provides a visual indication of system activity and changes state periodically while the application is running.

### LED Outputs 

### Description

GPIO outputs connected to the user interface status indicators. These outputs drive the LEDs used to display operating conditions, user selections, and appliance status information.

### Functionality

Receive status and indication commands from the MC Board through the GEA4 communication and drive the corresponding LED outputs to provide visual feedback of cycle status, active options, operating conditions, and user selections.


## 2. GPIO Inputs

### User Buttons

### Description

GPIO inputs connected to the user interface buttons. These inputs detect user interactions and communicate the corresponding button events to the MC Board through the GEA4 communication interface. 

### Functionality

Detect user button activations through the GPIO inputs, identify the corresponding button event, and transmit the event to the MC Board through the GEA4 communication interface. The MC Board processes the received command and executes the associated function, such as Start/Pause, Deep Rinse, or Wrinkle Care.


## 3. HaierLink Communication Interface

### Description

The interface allows data exchange between the UI board and MC board. The BUS_BUSY signal indicates communication bus availability and helps prevent communication conflicts.

### Functionality

- Transmit data to external system modules.                          //
- Receive data from external system modules.                         //
- Exchange control, status, and diagnostic information.              //
- Monitor communication bus availability through the BUS_BUSY signal.//


## 4. PWM Outputs

### Description

PWM output used to control the buzzer and generate audible feedback for user interactions and appliance operating events based on commands received from the MC Board.

### Functionality

Receive buzzer control commands from the Main Control Board through the GEA4 communication interface, generate the required PWM signal, and drive the buzzer to produce audible feedback associated with user interactions and appliance operating events. The PWM signal controls the buzzer tone characteristics to indicate selector changes, button activations, cycle startup, and cycle completion events.


## 5. ADC Inputs 

### Description

ADC inputs used to acquire the position of the cycle and temperature selector knobs and communicate the corresponding digital values to the Main Control Board.

### Functionality

Acquire the analog voltage generated by the selector knob, convert the measured voltage into a digital ADC value, and transmit the ADC information to the Main Control Board through the GEA4 communication interface. The Main Control Board evaluates the received value against a predefined lookup table containing the valid cycle and temperature ranges to identify the user-selected configuration and execute the corresponding function.
